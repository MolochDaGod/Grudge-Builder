Weapons Mastery

A point-allocation talent tree per weapon type. Spend a shared mastery pool — one point per character level — across any of the 9 trees. Each tree has 7 core nodes, 10 micro nodes for small passives/crits/procs, and a signature capstone (35 points to fully fill). This page is generated from the same shipped defs as the in-game tree.
