## Tome contents

- 6-hour game days / 8-day weeks (matches `gameClock.ts`)
- Eight day names (Firstdawn … Restday)
- Four seasons
- Gods: Odin, Madra, Omni
- Religions, gods’ days, events, tides & sky
- Live clock readout from wall time → game sky/tide
